AI-Based ECG Prediction System

An advanced machine learning approach for early detection of stroke and cardiac risks through ECG micro-dynamic analysis.

🚀 Try the App

Summary

Cardiovascular diseases remain the leading cause of death worldwide. This project aims to develop an AI system capable of detecting invisible micro-dynamic ECG changes that can indicate early coronary artery disease and pre-stroke risk.

The system leverages advanced deep learning architectures (CNN + LSTM) to detect subtle waveform changes that traditional analysis methods might overlook.

Methods

  • Data collected from multiple clinical ECG datasets.
  • Signal preprocessing using adaptive filtering for noise reduction.
  • Micro-dynamic features extracted from inter-beat variability.
  • Hybrid CNN-LSTM model trained for early pre-stroke pattern detection.
  • Achieved prediction accuracy up to 90%.

Results

✅ Model accuracy: 90% — outperforming prior ECG-based stroke predictors.

✅ Identified QRS complex as the key predictive ECG feature (60% influence).

✅ Enhanced stability under noisy ECG inputs.

Future Work

  • Integrate wearable real-time ECG devices.
  • Expand clinical dataset coverage for model generalization.
  • Include artery diameter and blood flow indicators.
  • Develop a web-based dashboard for live predictions.
