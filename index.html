CARDIAC PRE-STROKE

AI-Based ECG Prediction System

An advanced AI-driven cardiac system that predicts early stroke and heart attack risks using high-resolution ECG micro-dynamic analysis.

🚀 Try the App

💡 Project Summary

The CARDIAC PRE-STROKE project aims to develop an AI system capable of identifying early cardiac and stroke risks by analyzing subtle micro-dynamic changes in ECG signals.

Traditional diagnostic systems focus on visual ECG features, while our approach targets micro-level variations invisible to the human eye, providing a more sensitive and reliable early detection.

Using hybrid deep learning models (CNN + LSTM), the system interprets spatial and temporal signal dynamics to classify patients as normal or high-risk with an accuracy exceeding 90%.

🧠 Methods

  • ECG data collected from multiple medical datasets including healthy and pre-stroke subjects.
  • Signal preprocessing with adaptive noise filtering for high clarity.
  • Micro-dynamic feature extraction (min, max, SD, RR intervals) between consecutive heartbeats.
  • A CNN-LSTM hybrid model trained to detect subtle ECG anomalies.
  • Built Streamlit web prototype for real-time testing and visualization.
